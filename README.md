# 🌱 Krushi Mitra

Empowering Farmers Through Technology and Community.

## About
Krushi Mitra is a proposed AI-powered
agriculture assistance platform designed
to support farmers.

## Features
- Crop Photo Assistance
- Weather and Irrigation Guidance
- Simple Language Farming Assistant
- Agriculture Scheme Information
- Farmer Community Feedback

## Technologies
- HTML
- CSS
- JavaScript
- Proposed AI Integration

## Current Status
Interactive prototype demonstration.
AI diagnosis and live weather integration
are planned for future development.

## Future Scope
- Real AI-based crop assistance
- Live weather API integration
- Marathi language chatbot
- Mobile application development
